# Пакет независимой оценки

Четыре самостоятельных описания — `candidates/V01.md`…`V04.md`. Общие факты, диагностика, условия M04 и неизменная рубрика — `shared/`. Независимые проверки — `checks.json`, `finance.md`, `evidence.md` и таблицы `calculations/`.

Вначале оцените каждый вариант самостоятельно по обязательным gates и всем семи критериям 0–3, с основаниями. Затем объясните сопоставление и допустимый shortlist. Сумма баллов и экономия не выбирают победителя. Допустим отказ всем. Создавать гибрид или менять варианты не требуется.

Актуальное задание сохраняет основу фиксированных корпоративных начислений и старые права; основной фокус — дополнительное поощрение руководителями. Проверяйте стимул полезного вклада, понятность сотруднику, удобство руководителю, посильность HR, доступность/получение наград, выполнимость обязательств и привлекательность перехода с существующей платформы.

Финансовый pass относится только к явно названной проверенной сценарной области. CORE с 60% получения новых fixed не является полным обеспечением будущих начислений. LOW_FIXED96_FULL_NEW проверяет 100% всех новых fixed/R и сценарный старый спрос; низкая gross-эмиссия — допущение частоты событий при прежних ставках. Все старые права сохраняются, полный стресс их предъявления показан отдельно. Реальные параметры банка остаются неизвестными. Не превращайте сценарий в утверждение фактической обеспеченности.

В ресурсах различаются авторские границы и общая чувствительность шесть минут на оформление/получение каждой корзины. Полезная производственная работа показана отдельно от процедуры. Не считать неоценённую обычную работу бесплатной и не выбирать вариант механически по одной сумме.

В назначенный контекст не входят приватная карта, исходные папки вариантов, происхождение, прежние ранги и история выбора. Читайте этот пакет и skill `concept-review`; при необходимости используйте только указанные первичные локаторы. Оценка уверенности должна отражать фактическую глубину проверки, а не объём текста.
