# Роли и skills системы

Архитектура согласована с пользователем. Конфигурации созданы; реальный workflow, анализ и наполнение wiki **не запускались**. Основной агент чата — координатор, отдельного агента над ним нет.

| Область | Исполнитель | Skill / процедура | Результат |
|---|---|---|---|
| Знания | Основной агент по отдельному поручению | `knowledge-curation` | Тематическая wiki, источники, покрытие и прогресс |
| Координация | Основной агент | `case-iteration` | Ограниченный запуск, делегирование, отбор, снапшоты и остановка |
| План поиска | `iteration-planner` | Протокол и контракты case-iteration | Два задания с разными гипотезами и условиями отказа |
| Диагностика | `case-analyst` | `case-diagnosis` | Общая диагностика, данные, причины, ограничения и пробелы |
| Концепции | Два экземпляра `concept-developer` | Общий `concept-design` | Независимые варианты A/B на одинаковой фактической основе |
| Экономика | `financial-analyst` | `case-finance` | Модель, балансы, сценарии, чувствительность и gates |
| Доказательства | `evidence-researcher` / основной агент | `evidence-check` | Проверка значимых тезисов и точечный ресерч |
| Проверка и шортлист | Свежий `concept-reviewer` | `concept-review` | Независимая оценка, замечания, шортлист или отказ всем |
| Сведение и материалы | Основной агент | `case-storyline`, если входит в поручение | Аргументация, презентация и приложения |

Сценарии трёх групп, администрирование и внедрение входят в проработку концепции. Одна процедура используется обеими ветками, а разнообразие обеспечивается разными вопросами и механизмами.

## Ограничения первого запуска

Две параллельные ветки, до трёх итераций, до одного целевого возврата на исправление в цикле; остановка после двух циклов без содержательного улучшения или раньше по отсутствию полезной следующей проверки/ресурса. В первом цикле по две концепции с каждой ветки, далее по одной. Кандидаты и неизменённый предыдущий лучший вариант сравниваются с действующей программой как baseline.

Все роли одновременно не запускаются. Диагностика переиспользуется; исследователь подключается под реальный пробел. Планировщик, финансист и reviewer могут работать последовательно. Предел Codex — два дочерних агента, модели и разрешения наследуются.

Reviewer оценивает пакет без авторов и прошлых рангов; выбор с основаниями фиксирует координатор. Результат null допустим. Оценка 0–3 — экспертная категория, не измеренный эффект для банка.

`knowledge-curation` и `case-iteration` вызываются явно. Остальные skills применяются к назначенной задаче и сами работу не запускают. Настройка системы не отменяет запрет на текущую обработку raw. Изменение состава и лимитов фиксируется в [решениях](../../project/decisions.md).
