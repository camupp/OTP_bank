# Рабочие шаблоны

Это формы для отдельных артефактов, не самостоятельные агенты и не автоматически исполняемые workflows. Копируйте подходящий шаблон в рабочую папку и заполняйте только применимые разделы.

- [Задание исполнителю](task.md): цель, входы, область записи, результат и критерии приёмки.
- [Карточка источника](source-note.md): что именно прочитано и что подтверждает материал.
- [Аналитическая записка](analysis-note.md): вопрос, данные, способ расчёта, вывод и ограничения.
- [Проверка результата](review.md): замечания с доказательствами и границы проверки.

Обсуждаемые примеры skills и TOML-ролей лежат отдельно в [docs/agent-setup/templates/](../docs/agent-setup/README.md).
