# Oracle: только для независимого проверяющего

Этот каталог не входит в общий manifest, не читается source-reader/генератором, не является дополнительным источником для алгоритма и не выдаётся разработчикам кандидатов. Здесь нет правильного Q, ранга, суммы, impact_score или победителя. Факты сценарного конструирования и свойства устойчивости не требуют угадывать невидимый факт: отсутствие доказательства допускает pending/not_computable.

`case_controls.json` связывает пары/скрытые факты и направления проверок. Числа в нём, как и во всём fixture, — допущения, не данные банка. `manifest.sha256` отдельно фиксирует содержимое этого каталога. Доступный пакет и oracle нельзя смешивать при формировании назначенного контекста.

Свойства — условия для разбора расхождения, не автоматический рейтинг по числу пройденных случаев. Если иной допустимый смысл метрики объясняет расхождение, reviewer должен его описать. Родитель рассчитывается буквально, без исправления8закрытий ради одного крупного IT-результата. Если его выборка не обеспечена доступными актами, это not_computable, а не дорисованный QA.
