- Начальная библиотека: [реестр веб-подборки](../knowledge/raw/web_research_2026-10-26/07_source_register.md).

- Утверждения, которые реально используются в анализе: [claims.csv](claims.csv), пока только заголовки.

Новый файл называйте по исследовательскому вопросу, например `recognition-coverage.md`. В записке нужны вопрос, прочитанные источники, подтверждённое содержание, противоречия, ограничения и связь с кейсом.

У старых подборок собственные пространства ID: `S69` без пути неоднозначен. Указывайте, например, `web_research_2026-10-26:S69` и путь к карточке/оригиналу. Для новых утверждений можно использовать `CLM-0001`; это локальное соглашение, а не функция Codex.

Поля `kind` в реестре: `case_fact`, `source_claim`, `hypothesis`, `calculation`. Поле `evidence_status`: `unverified`, `supported`, `disputed`. Даже `supported` требует указать ограничение источника; причинность автоматически не подразумевается. Допущения с числовыми параметрами ведутся отдельно в `analysis/assumptions.csv`.
