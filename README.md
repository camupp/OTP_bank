# ОТП Мания — рабочая папка кейса

Здесь готовим решение кейса ОТП Банка для Changellenge Cup Moscow 2026: исследуем проблему признания сотрудников, анализируем отзывы, сравниваем концепции и проверяем экономику при фиксированном бюджете.

**Сейчас:** согласована и настроена система из шести профилей агентов и восьми skills. Основной агент координирует ограниченные итерации с двумя ветками, проверками, сравнением и снапшотами. Реальные итерации и обработка raw не запускались; wiki пока пустой каркас, итоговая концепция не выбрана.
