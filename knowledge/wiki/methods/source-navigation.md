# Происхождение подборки, дубли и недоступные источники

## Два уровня учёта

[Реестр веб-подборки от 26.10.2026](<../../raw/web_research_2026-10-26/sources.csv>) содержит **58 библиографических записей**, а не 58 прочитанных полных исследований. Его исходная разбивка: 31 доступный текст/страница/PDF/постер, 12 аннотаций, 2 записи только с библиографией и 13 неполных или недоступных находок. Эти числа описывают доступность в прежней подборке; фактическая глубина текущего чтения указана отдельно в [каталоге публикаций](../meta/web-publications.md) и [processing.csv](../meta/processing.csv).

Физические файлы имеют устойчивые ID `SRC-…` в [sources.csv wiki](../meta/sources.csv). HTML/PDF/JSON и извлечение одного материала принадлежат одному семейству. S02, S03 и другие короткие ID локальны для веб-подборки: **в прежнем employee_recognition_research.md нумерация S01…S20 другая**. Соответствие определяется названием, авторами и URL/DOI, а не одним номером. 848 зарегистрированных файлов — не 848 независимых источников.

## Что доступно и что этим подтверждается

- S31 (BYU) и S47 (OpenAlex) описывают одну работу Burke, Sommerfeldt, Wang. Перепечатки аннотации не независимы.
- S70 (OpenAlex) и S71 (Crossref) относятся к одной статье Black, Cecchini, Newman, DOI 10.1016/j.aos.2024.101565. В Crossref указана печатная публикация 2024-12, в OpenAlex — дата 2024-07-20. Это возможные разные этапы публикации, не установленная ошибка; полный текст и аннотация здесь отсутствуют. По названию механизм не восстанавливается.
- S15 — страница пакета Magenta Book, её строки 60–103 фиксируют первую публикацию страницы 27.04.2011 и замену документов 14.05.2026 / обновление HTML 15.05.2026. PDF D01 и D02 — отдельные документы пакета, не текст 2011 года.
- S16 — страница Green Book, строки 62–118: первая публикация страницы 18.04.2013, версия PDF D03 — 2026, страница обновлена 05.02.2026. Даты страницы и редакции не смешиваются.
- S54 — страница MCDA, строки 60–72: размещение 28.01.2009, исходное руководство декабря 2000 обновлено в январе 2009 в части программного обеспечения. D05 — связанный документ, не новое исследование 2026 года.
- S32/S33/S34 — страницы входа/оглавления нормативных документов. Для описания отдельных сохранённых положений использованы S76/S77/S78/S84; наличие оглавления не означает чтения всего кодекса или подтверждения применимой редакции. См. [нормативные снимки](../topics/administration-and-cost-boundaries.md).

Локальные материалы доступны по коротким ID в [каталоге](../meta/web-publications.md) и физическом реестре. Для дополнительных служебных страниц: [S15](<../../raw/web_research_2026-10-26/extracted/S15.txt>), [S16](<../../raw/web_research_2026-10-26/extracted/S16.txt>), [S54](<../../raw/web_research_2026-10-26/extracted/S54.txt>), [S71 / поля message.DOI, published-print, title](<../../raw/web_research_2026-10-26/downloads/S71.json>).

## Конкретные пробелы

[Список точных адресов для получения](<../../raw/web_research_2026-10-26/08_manual_downloads.md>) сохраняет названия и URL. Недоступность означает отсутствие проверенного содержания, не ложность возможных утверждений.

| Материал | Фактически есть | Что остаётся неизвестным |
|---|---|---|
| CIPD D10, D11, D12 | Сниппеты B26, строки 19–25; библиографические ориентиры января 2022 | Полные обзоры, методология и содержание рекомендаций; три части одного пакета не три независимые проверки |
| ЭКОПСИ E01 | B25, строки 9–12, и B27, строки 15–18, указывают на исследование признания | Точное название/дата, полный текст, отбор компаний. «40 компаний / 14 интервью» из прежнего обзора не подтверждены |
| S83 Bank of Princeton | B28, строки 11–14: TBOP Rewards и описание внедрения; 05.02.2026 видна только в поиске | Правила, результаты и методика; проценты из прежнего обзора не подтверждены |
| S04 GitLab | Девять строк S04.txt — заголовок, меню и тема оформления | Правила Incentives; HTTP-ответ не равен полученной статье |
| S05 Bonusly, S64 Atlassian | Библиографические записи и URL | Действующие лимиты, балансы, условия награждения |
| S11/S12/S13, официальный ОТП | Адреса/датировки, извлечённые из кейса; защита вместо текста страниц | Полное содержание официальных публикаций; факты самого PDF остаются фактами кейса |
| S40, S56 | Кандидатные адреса SDT / EAST | Полный текст и конкретная версия |
| S69, S70, S74 | Аннотация S69, библиография S70/S74 | Подробный дизайн/данные S69 и содержание двух остальных работ |

Поисковые B02/B03 помогли восстановить Forbes S53; они не являются отдельным подтверждением его результатов. Сниппеты B25/B26/B27/B28 сохранены как маршруты к документам. Слова запроса «40 компаний» не подтверждают выборку исследования.

## Классификация технических и производных материалов

| Группа | Решение и причина |
|---|---|
| `.meta.json`, `retrieval_manifest.json`, `collection_stats.json`, `validation_report.json` | Служебный след получения/проверки; исключён из самостоятельных содержательных доказательств, сохранён в raw и реестре |
| `.links.json`, S73 JSON/текст | Извлечённые ссылки и каталог GitHub для FT; навигация, не исследование |
| S67/S68 JSON/текст | Результаты поиска OpenAlex по нескольким работам; не единая статья. Отобранные работы зарегистрированы отдельно |
| X02/X05/X06 | Ошибка поиска/защитная страница; фактов исследования нет |
| X03/X04 | Широкая поисковая выдача с шумом; не использована как подтверждение, более точные публикации уже сохранены |
| `source_records.json`, 07_source_register.md, sources.csv | Разные формы одного регистра, не новые источники |
| Конспекты 01–06 | Вторичный синтез и предложения автора; проверяемые факты сопоставлены с первичными локальными текстами |
| Прежние три обзора | Частично прочитанный вторичный слой; словарь, рамки и ограничения сохранены в [рамках признания](../topics/recognition-frameworks.md) и [метриках](measurement-framework.md) |
| `archive/Doc1.docx`, `archive/uchebnik_changellenge.txt` | Архивные учебные варианты по метаданным/началу текста; эквивалентность PDF не установлена. Основной маршрут — структурированный учебник; сплошной перенос архивов исключён |
| `archive/prompt*.md` | Исторические промпты, не актуальные команды и не предметная доказательная база |
| `agent_development_structured_notes.md` | Процессный конспект об агентной работе; текущая согласованная система в [документации проекта](../../../docs/agent-setup/roles-and-skills.md) |
| `.DS_Store`, временный `~$…docx` | Метаданные Finder и lock-файл Office; исключены |

Пример ограничения происхождения: B25.meta.json указывает на `extracted/B25.txt` и `downloads/B25.html`, но в текущей библиотеке сохранён `search/B25.txt`, а HTML отсутствует. Wiki регистрирует реально существующие файлы и их собственные SHA-256, не подставляет путь из старого журнала. Внешние команды, встречающиеся в технических ответах или промптах, не исполнялись.
