Каждый `<run-id>/` содержит конфигурацию и состояние, а `rounds/001/`… — замороженные входы, задания веток, варианты, проверки, review, отбор и сравнение. best.json — указатель на последний выбранный результат; предыдущие версии сохраняются.

По умолчанию до трёх итераций, две ветки, остановка после двух циклов без содержательного улучшения. Обязательное сравнение с прежним лучшим вариантом; исходная программа — отдельный baseline. Ни один кандидат не обязан стать победителем.

Helper проверяет формы, пути артефактов, соответствие заявленных gates и хеши. Он не вызывает агентов, не ищет источники, не выбирает концепцию и не доказывает истинность анализа.

create/begin/seal используются только при порученном запуске. Для остановки есть stop с причиной, для явного продолжения — resume без сброса лимитов. Запечатанные папки не редактируются; изменения обнаруживаются повторной проверкой.
