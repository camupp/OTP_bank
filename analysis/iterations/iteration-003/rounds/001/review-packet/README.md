# Назначенный пакет проверки

Четыре спецификации V01–V04 оцениваются по одной замороженной рубрике. Происхождение, авторство и прежние ранги не назначены reviewer.

Входы: ../inputs/{context,evidence,diagnosis,baseline}.md и rubric.json; верхние дополнения C05/C06/D02/M02 имеют приоритет над сохранённым историческим текстом. Кандидаты: candidates/V01.md…V04.md; параметры: specifications/; консолидированные проверки: checks.json; расчёты и отчёты: finance/; доказательства: evidence/.

Числа сценарные, реальный бюджет/ресурсы банка не подтверждены. Финансовые pass относятся только к раскрытому scope; стрессовые отказы и неисполненные права сохраняются. Все необходимые полномочия/ресурсы должны быть проверены перед реальным пилотом. Экономия от сокращения будущих прав не эффект признания.

Обезличенные программные/текстовые копии могут иметь иные хеши, чем оригиналы исполнения; manifest ниже подтверждает именно назначенные копии. Не запускайте экспортирующие model.py: проверяйте их и таблицы чтением либо отдельными формулами без изменения файлов. Запуск моделей для независимой проверки при необходимости только с изолированным временным OUT, без доступа к приватной карте/истории.
