# Презентация и материалы команды «Крюки»

Актуальный комплект находится в [iteration-008](iteration-008/). Команда, согласованные функциональные роли и ссылка на GitHub заполнены.

- **[Презентация PDF](iteration-008/CupMoscow2026-ОТП-Крюки.pdf)** — 8 основных слайдов для самостоятельного чтения и 19 приложений с подробностями.
- [PowerPoint](iteration-008/CupMoscow2026-ОТП-Крюки.pptx) — редактируемые слайды.
- [Excel](iteration-008/CupMoscow2026-ОТП-Крюки.xlsx) — допущения, финансы и сценарии, 8 листов.
- [Архив](iteration-008/CupMoscow2026-ОТП-Крюки.zip) — весь комплект, включая поясняющие документы.
- [Карта источников](iteration-008/source-map.md) — точные места в первичных материалах и назначение листов модели.
- [Логика презентации](iteration-008/storyline.md), [пояснения](iteration-008/defense-notes.md) и [проверка требований](iteration-008/requirements-check.md).

Числа модели — сценарные оценки; эффект для ОТП не измерен. Требования к сдаче сохранены в [постановке](../project/brief.md): 8 основных слайдов с титулом и командой, PDF до 18 МБ, приложения вне лимита; Excel рекомендован.

Исходник текущей сборки — `.build/build_read_deck.py`, точка входа — `.build/deck.mjs`; данные команды — [project/team.json](../project/team.json). Для сборки нужен Python 3, для экспорта PDF — LibreOffice. В `.build/source-template/` сохранена неизменяемая основа презентации и книги; локальные промежуточные экспорты и резервные копии не входят в коммит.

После изменений слайдов нужно повторно экспортировать PDF, проверить комплект и обновить архив с `delivery-manifest.json`. Сборка файлов не отправляет их организаторам.
