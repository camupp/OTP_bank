# Диагностика кейса и отзывов


Применяй к назначенной диагностике; настройка этого skill не разрешает анализ источников.

1. Установи вопрос, назначенные файлы, период и единицу наблюдения. Используй соответствующие инструкции `analysis/AGENTS.md` и подготовленные знания; оригинал открывай для проверки конкретного места.
2. Проверь поля, пропуски, повторы, диапазоны дат и знаменатели до выводов. Не считай повторяющуюся анонимную подпись уникальным человеком; не вычисляй стандартный NPS по «Да/Нет».
3. Для текстов опиши схему тем, разреши несколько кодов и «неясно», проверь выборку и неоднозначные случаи. Сохраняй locator цитат и правила преобразования. Отзывы покупателей не описывают автоматически весь штат.
4. Построй диагностику: наблюдение → возможная причина → подтверждение/опровержение → неизвестное. Рассмотри конкурирующие объяснения, не выдавая выбранную причину за доказанную.
5. Верни diagnosis.md и при необходимости производные таблицы в назначенной области: проверенные факты, дерево причин, данные/коды, ограничения, общие основания для концепций, точные пробелы. Выбор концепции не входит в диагноз.

Для входного пакета координатору нужна компактная версия с восстановимыми ссылками, а не полный журнал анализа. Новые источники и реестры интегрирует назначенный ответственный; не редактируй чужие области.
