**Актуально,31.10.2026:** завершена [iteration-005](analysis/iterations/iteration-005/report.md):3раунда,8новых версий. Рабочая рекомендация — **CON-015@v1**, понятный нижний уровень, четыре отделовых top-места40/30/20/10 и отдельно подтверждённый особый вклад; корпоративные fixed/платформа/старые права сохранены, самонаграждение исключено правилами. Независимые проверки и свежие review выполнены, [три снимка](analysis/iterations/iteration-005/state.json) закрыты, остановка поiteration_limit. Сценарный допуск отличается от реального внедрения/эффекта. [Короткая карточка](analysis/iterations/iteration-005/rounds/003/branches/B/employee-card.md), [нюансы](analysis/iterations/iteration-005/nuance-register.md). Ниже — история прежних запусков.
