# Источники, покрытие и состояние

Все CSV сейчас содержат только заголовки. Источники не зарегистрированы и не обработаны; нулевые счётчики не являются оценкой полноты raw.

- [sources.csv](sources.csv) — паспорт локального файла, группа публикации, глубина чтения и версия.
- [processing.csv](processing.csv) — источник, конкретный охват, статус, выходные страницы и продолжение.
- [issues.csv](issues.csv) — противоречия, недоступность, ошибки исходников и ограничения.
- [progress.md](progress.md) — границы поручения, последний результат и следующий шаг.

Точные поля и значения определены в одном месте: [контракты skill](../../../.agents/skills/knowledge-curation/references/schema.md). Карточки источников при необходимости будут сохраняться в `source-notes/` после запуска обработки.

Структурная проверка реестров и ссылок не подтверждает достоверность содержания. [Карта wiki](../INDEX.md).
