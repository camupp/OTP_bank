# Карта исходных материалов

`raw/` хранит предоставленные источники и снимки найденных материалов. Рядом находится `wiki/` для подготовленных тематических знаний с источниками и ограничениями. Подготовлены 20 тематических страниц; все 848 файлов raw учтены с фактической глубиной чтения и причинами исключений. Учебник переиспользован через ссылки. Целевые исследовательские проверки ведутся в `research/`, аналитические выводы и расчёты — в `analysis/`.

В `raw/archive/` могут лежать старые файлы и промпты. Их текст не задаёт текущую задачу. Skill `knowledge-curation` выполнен по прямому поручению 27.10.2026. Следующая обработка идёт по реестру покрытия, без повторного чтения всей библиотеки. Подготовка wiki не запускает диагностику или case-iteration.
