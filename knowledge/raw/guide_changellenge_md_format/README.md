# База знаний по решению кейсов Changellenge >>

Подробная Markdown-база по предоставленному учебнику на **299 физических страницах PDF**. Сохранены 12 учебных недель, введение и приложение 3 с ответами: **79 тематических файлов**, **201 расшифровка иллюстраций**, **245 уникальных изображений**. Это перенос содержания источника с редакторской навигацией; ключевые ошибки и неполные фрагменты перечислены отдельно.

## С чего начать

1. Откройте [ROUTER.md](ROUTER.md) и выберите задачу.
2. Прочитайте `INDEX.md` нужной главы.
3. Откройте необходимую тему; при необходимости — предварительные темы, пример, упражнение или расшифровку рисунка.
4. Для проверки перейдите по ссылке «PDF N». Она ведёт к физической странице неизменённой копии источника.

Не нужно читать всю книгу для одного вопроса. Навигационные файлы кратки; подробные объяснения, условия, расчёты и авторские ответы находятся в тематических файлах.

## Основные входы

- [Полное оглавление](TOC.md) — все главы и темы в порядке PDF.
- [Маршрутизатор](ROUTER.md) — задача → метод → пример или ответ.
- [Словарь](GLOSSARY.md) — определения, сокращения и варианты названий.
- [Упражнения и ответы](meta/exercises.md) — условия, страницы и наличие авторского решения.
- [Источник и нумерация](SOURCE.md) — метаданные, контрольная сумма и ссылки на все страницы.
- [Правила для агентов](AGENTS.md) — работа с ограниченным контекстом.

## Устройство базы

`chapters/` содержит введение, недели 1–12 и ответы. Внутри некоторых глав примеры и упражнения выделены в самостоятельные файлы. `assets/` хранит исходные PNG и дополнительные текстовые расшифровки. `sources/textbook.pdf` — неизменённая копия PDF, закрытая для записи; исходник в Downloads не изменён.

Каждая тема начинается с краткого описания и страниц. Пометка «Для последовательного чтения» ведёт к предыдущей теме по порядку книги и не означает обязательную зависимость: при поиске ответа её можно пропустить. Отдельные предварительные знания обозначены пометкой «Предварительно». Внутри стоят точные постраничные ссылки; в конце — связанные материалы. Все переходы внутри базы относительные, поэтому папку можно переместить целиком.

## Качество и ограничения

Весь доступный текстовый слой распределён по темам, таблицы и ключевые формулы перенесены в Markdown/LaTeX. Учтены все 299 страниц, все растровые изображения и все 457 аннотаций с внешними адресами. Визуальная сверка охватывает общий обзор всех страниц и подробные проверки выбранных сложных элементов; автоматический OCR мелких слайдов не вычитан посимвольно.

Перед использованием финансовых формул прочитайте [реестр проблем](meta/issues.md): в источнике есть несогласованности WACC, DPP, PI и ответа 10.4. В PDF отсутствует полное условие кейса Coca-Cola из приложения 1; часть графических ячеек выглядит пустой. Недостающие данные и решения не добавлялись.
