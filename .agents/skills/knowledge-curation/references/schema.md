# Контракты wiki и реестров

Пути ниже считаются от корня проекта. CSV записываются в UTF-8, разделитель — запятая, списки ID и выходных путей внутри ячейки — через `;`. Используй CSV-писатель для запятых и переносов в значениях. Реестры сейчас пусты намеренно; записи появляются при порученной обработке.

## `knowledge/wiki/meta/sources.csv`

| Поле | Смысл |
|---|---|
| `source_id` | Уникальный устойчивый ID локального файла, например SRC-0001 |
| `relative_path` | Путь относительно `knowledge/raw/`; существующий файл в этой области |
| `source_group` | Общая публикация/семейство источников: оригинал, извлечение, версии |
| `source_type` | Например case, organizer, research, vendor_case, review, textbook, dataset, process_note, prompt, derived, technical |
| `publication_date` | Дата публикации, если известна; не дата скачивания |
| `data_period` | Период наблюдений/данных, если есть |
| `origin_url` | Исходный внешний адрес, если установлен |
| `reading_depth` | none, metadata, snippet, abstract, sections, full |
| `content_sha256` | SHA-256 фактически зарегистрированного локального файла |

Дата получения, авторы, доступность и исходные ID при необходимости раскрываются в карточке `meta/source-notes/SRC-0001.md`, созданной по шаблону skill. Отсутствующие библиографические сведения обозначаются как неустановленные, а не достраиваются.

## `knowledge/wiki/meta/processing.csv`

| Поле | Смысл |
|---|---|
| `unit_id` | Уникальная единица обработки, например UNIT-0001 |
| `source_id` | Существующий source_id |
| `scope` | Физические страницы PDF, разделы, лист/диапазон либо объяснимый охват файла |
| `status` | Один из статусов ниже |
| `source_sha256` | Версия файла, к которой относится обработка этой порции |
| `outputs` | Пути к существующим страницам относительно `knowledge/wiki/` |
| `next_step` | Конкретный необработанный диапазон / действие для продолжения |
| `reason` | Причина исключения, блокировки или повторного использования |
| `updated_at` | Дата последнего изменения записи |

Статусы:

- `pending` — учтено, ещё не обрабатывалось.
- `in_progress` — текущая порция, результат не завершён.
- `partial` — часть содержания сохранена, указано откуда продолжать.
- `processed` — содержание указанного scope сохранено, связано с источником и проверено в пределах заявленной глубины чтения.
- `reused` — используется существующий структурированный слой; указан его выход и причина. Не приравнивать к повторному полному чтению.
- `excluded` — исключено с объяснением, а не потеряно.
- `blocked` — недоступность/нечитаемость не позволила завершить; указаны причина и возможный следующий шаг.
- `outdated` — результат относится к старой версии; прежние хеш/охват сохраняются для проверки истории.

Для `processed` и `reused` нужны выходные файлы и хеш, совпадающий с зарегистрированной версией источника. Закрытая порция не означает обработку остального файла. Перекрытие scope допустимо только с объяснением; не считать его новым охватом.

## `knowledge/wiki/meta/issues.csv`

Поля: `issue_id,source_refs,kind,description,status,wiki_paths,next_step`.

`source_refs` — source_id через `;`; `wiki_paths` — пути от wiki. Типы проблем свободные: contradiction, missing_text, OCR, source_error, missing_metadata, unavailable. Статусы: `open`, `resolved`, `accepted_limitation`. Последний означает раскрытое ограничение, не подтверждение спорного тезиса.

## Тематическая страница

Файл в `case/`, `topics/` или `methods/` имеет YAML-frontmatter:

```yaml
title: "Точное название темы"
status: draft
updated: "YYYY-MM-DD"
source_refs: ["SRC-0001"]
```

Для `source_refs` используй именно однострочный JSON-совместимый массив строк; это валидный YAML и позволяет проверить ID без дополнительных библиотек. Все ID должны существовать в sources.csv.

Статусы страницы: `draft`, `reviewed`, `needs_review`. `reviewed` означает проверку ссылок и атрибуции в заявленном объёме, а не научную сертификацию всех источников. Внутри страницы у каждого значимого утверждения должен быть точный locator; список source_refs не заменяет ссылки рядом с утверждением.

README разделов — только навигация и не считается содержательным выходом порции. Карточки источников в `meta/source-notes/` не заменяют тематическое структурирование.

## `meta/progress.md` и `INDEX.md`

В прогрессе сохраняй текущий scope поручения, последнюю завершённую порцию, проверки, открытые пробелы и точный следующий шаг. В INDEX включай только реально существующие страницы; подготовленные разделы помечай пустыми. В состоянии `not_started` нет обработанных источников и тематических страниц.
