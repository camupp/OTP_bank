# Роли системы

Координатор — основной агент текущего чата. Другие роли:

| Профиль | Назначение |
|---|---|
| [iteration-planner](iteration-planner.toml) | Два обоснованных направления следующего цикла, проверяемые задания и критерии отказа |
| [case-analyst](case-analyst.toml) | Общая диагностика и анализ назначенных отзывов, без выбора концепции |
| [concept-developer](concept-developer.toml) | Один профиль, два независимых экземпляра A/B с разными заданиями и owned_paths |
| [financial-analyst](financial-analyst.toml) | Сопоставимая экономика, потоки валюты, сценарии и чувствительность |
| [concept-reviewer](concept-reviewer.toml) | Независимые gates, рубрика и шортлист; допускается отказ всем |
| [evidence-researcher](evidence-researcher.toml) | Проверка конкретных утверждений и точечный добор доказательств |

Модели и разрешения не переопределены. Исполнители не создают других агентов и не меняют общие входы/реестры. Свои результаты пишут только в назначенные области. Для reviewer назначается пакет без прежних рангов и авторства; это правило контекста, не техническая песочница.

[Матрица ролей и skills](../../docs/agent-setup/roles-and-skills.md) · [Протокол](../../.agents/skills/case-iteration/references/protocol.md).

Установка профилей не означает, что роли запускались. В текущем этапе выполняется только построение и техническая проверка системы.
