# ОТП Мания — рабочая папка кейса

Здесь готовим решение кейса ОТП Банка для Changellenge Cup Moscow 2026: исследуем проблему признания сотрудников, анализируем отзывы, сравниваем концепции и проверяем экономику при фиксированном бюджете.

**Актуально, 01.11.2026:** [iteration-008 завершён](analysis/iterations/iteration-008/report.md), механика CON-025 сохранена, выбран отчётный способ внедрения CON-026@v2. [Комплект для сдачи](deliverables/iteration-008/): PPTX,PDF,XLSX,storyline,защита и проверка. Осталось заполнить название команды,имена и роли; файлы явно отмечают пробелы. Начинайте продолжение с [текущего статуса](project/status.md),не с исторической записи006 ниже.

**История, 31.10.2026:** завершён [iteration-006](analysis/iterations/iteration-006/report.md): один раунд, две ветки, один возврат. Условная рабочая основа — **CON-016@v2**, гарантия2500R за фиксированное полугодовое достижение раз в12месяцев при контрольномE24. Полезность500руб. — гипотеза; меньшеtop, поздние когорты и годовой пропуск раскрыты. [Решение](analysis/iterations/iteration-006/rounds/001/selection.json) и [снимок](analysis/iterations/iteration-006/rounds/001/snapshot.json) сохранены, остановка поiteration_limit. Corporate fixed/личные права сохранены, самоодобрение исключено. Сайт/презентация/raw→wiki тогда не запускались. Ниже — история прежних запусков.

**Обновление 29.10.2026:** в wiki добавлены [ответы организаторов](knowledge/wiki/case/organizer-clarifications.md) и [разборы трёх старых работ](knowledge/wiki/methods/past-cases-and-transfer.md). Новые уточнения разрешают пересматривать механики программы; прежний запечатанный пилот остаётся историей на старых входах.

**Предыдущий аналитический запуск, 30.10.2026:** завершена [новая итерация iteration-002](analysis/iterations/iteration-002/report.md). Рабочая сценарная рекомендация — [CON-005 «Подтверждённая польза»](analysis/iterations/iteration-002/rounds/001/branches/A/concept.md); CON-006 с равным ежегодным подарком сохранена как альтернатива.
