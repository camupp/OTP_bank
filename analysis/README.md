# Анализ кейса

Последний результат — [iteration-006](iterations/iteration-006/report.md): один раунд, две ветки, один возврат; условная рабочаяCON-016@v2 с гарантией2500R за фиксированное полугодовое достижение раз в12месяцев. [Сравнение](iterations/iteration-006/rounds/001/comparison.md), [финансы](iterations/iteration-006/rounds/001/checks/finance.md), [review](iterations/iteration-006/rounds/001/review.md) и [снимок](iterations/iteration-006/rounds/001/snapshot.json) сохранены. Старые запуски — история; реальная готовность и эффект неизвестны.

Здесь хранятся диагностика, разбор отзывов, концепции и финансовые проверки. Подготовлены [общая диагностика и пакет](preparation/README.md), [методические допущения](assumptions.csv) и [система итераций](iterations/README.md). [Пилот pilot-001](iterations/pilot-001/pilot-report.md) завершил одну итерацию: четыре концепции, проверки с baseline, независимое ревью и запечатанный снимок. Допустимого победителя нет из-за критических финансовых неизвестных.

Планируемые артефакты, по мере появления задачи:

| Область | Возможный результат |
|---|---|
| Отзывы | Профиль данных, правила очистки, темы, проверяемые цитаты и ограничения выборки |
| Проблема | Дерево причин и гипотез с подтверждениями и пробелами |
| Альтернативы | Сравнение 3–5 концепций по единым критериям |
| Экономика | Потоки и остатки валюты, бюджет, сценарии погашения и чувствительность |
| Эффект | Дерево метрик, дизайн проверки, границы причинных выводов |
| Пользователи | Сценарии сотрудника, руководителя и администратора |

Создавайте подкаталоги под реальные артефакты, а не заранее под каждую строку. Вычисления можно выполнять в таблице или небольшим воспроизводимым скриптом; стек разработки сейчас не устанавливается.

Схема записи результата — [analysis-note.md](../templates/analysis-note.md). Отдельно сохраняйте исходные данные, преобразованный набор и объяснение преобразования. Единица наблюдения, исключения и знаменатели должны быть восстановимы.

В `assumptions.csv` записаны аналитические соглашения подготовки: единица строки, сохранение совпадений, чувствительность и тематическое кодирование. Проектные допущения концепций сохранены в их ветках; общий [финансовый реестр пилота](iterations/pilot-001/rounds/001/checks/finance/assumptions.csv) отдельно различает факты, неизвестные и синтетические примеры. Для каждого нового параметра укажите значение, единицу, период, основание, источник или отсутствие данных и влияние на результат. Не помечайте сценарное допущение фактом банка.
