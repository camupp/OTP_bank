# Анализ кейса

Здесь будут диагностика, разбор отзывов, сравнение вариантов, метрики, сценарии пользователей и финансовая модель. Подготовлены правила, [реестр допущений](assumptions.csv) и [система итераций](iterations/README.md). Реального анализа и run-папок пока нет.

Планируемые артефакты, по мере появления задачи:

| Область | Возможный результат |
|---|---|
| Отзывы | Профиль данных, правила очистки, темы, проверяемые цитаты и ограничения выборки |
| Проблема | Дерево причин и гипотез с подтверждениями и пробелами |
| Альтернативы | Сравнение 3–5 концепций по единым критериям |
| Экономика | Потоки и остатки валюты, бюджет, сценарии погашения и чувствительность |
| Эффект | Дерево метрик, дизайн проверки, границы причинных выводов |
| Пользователи | Сценарии сотрудника, руководителя и администратора |

Создавайте подкаталоги под реальные артефакты, а не заранее под каждую строку. Вычисления можно выполнять в таблице или небольшим воспроизводимым скриптом; стек разработки сейчас не устанавливается.

Схема записи результата — [analysis-note.md](../templates/analysis-note.md). Отдельно сохраняйте исходные данные, преобразованный набор и объяснение преобразования. Единица наблюдения, исключения и знаменатели должны быть восстановимы.

В `assumptions.csv` сейчас только заголовки. Для каждого реально использованного параметра укажите значение, единицу, период, основание, источник или отсутствие данных и влияние на результат. Не помечайте сценарное допущение фактом банка.
