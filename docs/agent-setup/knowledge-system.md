# Система raw → wiki

Статус: система создана, содержательная обработка **не запускалась**. Настроен один проектный skill `knowledge-curation`; отдельный custom agent-куратор пока не нужен и не создаётся.

## Слои

- `knowledge/raw/` — оригиналы и снимки источников.
- `knowledge/wiki/` — подготовленные тематические знания с происхождением, ограничениями и навигацией. Сейчас это пустой каркас.
- `research/` — целевой поиск и проверка конкретных утверждений.
- `analysis/` — диагностика, новые расчёты, сравнение вариантов и выводы для ОТП.

Источники относятся к разным типам и имеют разную глубину проверки. Полнота будущей работы обеспечивается учётом назначенной области: что обработано, частично прочитано, повторно используется, исключено или осталось недоступным. Число страниц wiki не является показателем полноты.

## Явный вызов

В `agents/openai.yaml` установлено `allow_implicit_invocation: false`, поскольку пользователь хочет сам выбирать момент запуска. Создание или правка skill не считается разрешением переносить raw. Расписаний, hooks и фонового запуска нет.

Примеры будущих поручений, **не выполненные при установке**:

```text
Используй $knowledge-curation: обработай только первичный кейс ОТП в wiki.

Используй $knowledge-curation: продолжи с места, записанного в meta/progress.md.

Используй $knowledge-curation: проверь уже созданные страницы и версии их источников.
```

После назначения объёма skill должен выполнять его без нового согласования каждой порции. Если позже потребуется отдельный агент, он сможет применять этот же skill без второй копии процедуры.

## Что проверено на этапе установки

Штатный `quick_validate.py` подтвердил формат skill; YAML-метаданные и `allow_implicit_invocation: false` проверены. Проверены 91 локальная ссылка в связанных настройках и документах, отсутствующих целей не найдено.

Структурная проверка рабочей wiki прошла: 0 источников, 0 единиц обработки, 0 тематических страниц, ошибок нет. Дополнительно валидатор проверен на искусственных файлах только во временной папке: допустимую структуру принимает, битую ссылку и несогласованную версию источника отклоняет. Эти проверки не являются запуском skill или обработкой реальных материалов.

Приёмочная проба на кейсе, исследовании или обзоре отложена по запросу пользователя. Достоверность будущего содержательного переноса этими техническими проверками не установлена.

Обнаружение навыка проверяется в доступном интерфейсе/новой сессии Codex; создание файлов не является доказательством его появления в уже открытом селекторе. Основания формата Codex — в [официальных источниках](official-sources.md).
