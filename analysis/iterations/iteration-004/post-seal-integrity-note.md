# Проверка после запечатывания

Helper штатно скопировал выбранный обезличенный документ побайтно из review-packet/candidates в selected.md. Относительные ссылки при такой копии меняют базу. Чтобы сохранить закрытый снимок без правок, рядом с001, в rounds/, созданы относительные ссылки на канонические checks.json, finance.md, evidence.md, calculations/ и shared/ внутри запечатанного review-packet. Они восстанавливают переходы из selected.md; содержимое снимка не менялось.

Канонические результаты и исходная концепция доступны через report.md. Старые и новый снимки повторно проверяются по хешам; факты/механика/выбор не изменены.
