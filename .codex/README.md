# Проектная конфигурация Codex

Система настроена для итерационного решения исследовательского кейса. Координатор — основной агент чата; [роли](agents/README.md) описаны в отдельных TOML.

`config.toml` задаёт `agents.max_concurrent_threads_per_session = 2`: максимум два дочерних агента, основной не входит в этот счётчик. Это соответствует двум параллельным веткам. Модель, reasoning, provider, MCP и разрешения наследуются; глобальный `~/.codex/` не меняется.

Файлы не запускают работу сами. Workflow начинается по прямому поручению `$case-iteration`; наполнение wiki отдельно управляется `$knowledge-curation`. Создание системы и проверки на искусственных файлах не являются их запуском.

[Устройство системы](../docs/agent-setup/README.md) · [Процесс](../docs/agent-setup/workflow.md) · [Официальная документация](../docs/agent-setup/official-sources.md).

Проектные `.codex/` слои применяются в доверенной папке поддерживаемым клиентом. Обнаружение ролей и skills может потребовать новой сессии; реальный вызов ролей на этом этапе не проверялся. Для инструмента без параметра custom profile протокол предусматривает передачу тех же инструкций в задаче исполнителю.
