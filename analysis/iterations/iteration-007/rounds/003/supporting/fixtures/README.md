## Разделение доступа

- **Общий доступный source-пакет:** `source/base.json`, `source/scenario_index.json`, `source/reader.py`, `patches/F01.json`…`F12.json`, этот README, `dictionary.md`, `assumptions.csv`, `manifest.json`/`manifest.sha256`. Source-пакет одинаков для всех кандидатов и родителя.
- **Координатор/проверяющий:** `generator.py`, `validation.json`. Генератор не читает и не содержит oracle; разработчикам его назначать не требуется. Сводки validation — проверка структуры, не рассчитанные Q/награды.
- **Только независимый проверяющий:** `oracle/`. Каталог не входит в общий manifest и не читается ни `source/reader.py`, ни генератором. Не выдавать его разработчикам кандидатов. Разделение — правило назначенного контекста, а не изоляция файловой системы.

В обоих слоях отсутствуют готовые Q, impact_score, уровни normal/stretch, правильный ранг или сумма награды. `process_service_contract_share=0.95` — сценарный заранее утверждённый контракт качества процесса, не наградный порог/уровень. Кандидаты проспективно определяют собственные нормы признания; исходы не подбираются по их результатам.

## Объём и единицы

P1 = 01.01–31.03.2026, P2 = 01.04–30.06.2026; quality-close 28.04/28.07. Одно фиксированное годовое окно W2026-A, 01.01–31.12.2026. Часовой пояс Europe/Moscow, ISO timestamps с `+03:00`. Эти даты и все штатные/временные/инженерные значения — **допущения**, см. `assumptions.csv`.

В каждом семействе ровно две заранее зарегистрированные сравниваемые единицы: поддержка S01/S02 (работники), бэк-офис B01/B02 (работники), проекты T01/T02 (команды). Члены T01: P01/P02; T02: P03/P04. ## Чтение и парные сценарии

`source/reader.py` читает только доступные `source/base.json` и один patch. Модуль не импортирует генератор/oracle и не считает банковские показатели:

```python
# Если текущая папка — iteration-007-source-fixtures:
from source.reader import expand_scenario

case = expand_scenario('F02.inflated')
# Эквивалентно: expand_scenario('F02', 'inflated')
```

Для вывода развёрнутой выгрузки: `python3 source/reader.py F07.split`. Наличие нескольких вариантов требует явного имени; «первый» вариант молча не выбирается. Все варианты, если не оговорено ниже, применяются **к одной неизменной базе**, а не друг к другу. F10.restored — снимок восстановленного состояния той же базовой партиции после F10.lost, без копирования всех таблиц.

## Проверка и границы

Координатор может воспроизвести файлы командой `python3 generator.py`; `python3 generator.py --verify` проверяет уже записанную базу/patches. Проверяются ключи, ссылки на случаи/события, интервалы периодов, размеры, состав команд/суммы долей≤1, классификатор, фактически полученные числа/хеши партиций,22развёрнутых варианта и детерминированное повторное создание. Точный дубль F05 допускается как намеренная физическая ошибка экспорта; базовые ключи уникальны. Порядок строк не является метрикой; структурная проверка перестановки не заменяет проверку алгоритма кандидата. Хеш-выборка родителя/его QA и любые награды здесь не исполнялись.

`manifest.json` содержит SHA256 и размер каждого общего файла, кроме самого себя/manifest.sha256, oracle и временных __pycache__. SHA самого manifest лежит в `manifest.sha256`. После фиксации общего SHA пакет не менять; следующая версия требует явного нового manifest. Manifest включает генератор/структурную проверку для воспроизводимости, но не делает их обязательным контекстом разработчика.

Потерянная партиция отличается от полученной пустой: `availability`, expected/received и readiness сохраняются. Missing/null — не ноль качества, не автоматический провал и не готовое право. Факт без доступного подтверждения допускает pending/not_computable. Нет отдельных данных, доказывающих зарплатную ценность, эффект мотивации, экономию, пригодность инфраструктуры или кассовую устойчивость на7200человек. Нет личных наградных сумм. Инженерные нормы/временные доли могут быть оспорены как сценарные предположения, но не подменены после просмотра результатов.

Существующий QA (`existing_minutes`) отделён от новых предположений о настройке/проверке/подписи/исключении/восстановлении в `resource_assumptions`. Это минуты **на единицу** с названным объёмом; не вся прежняя QA-деятельность становится новым расходом или свободным ресурсом. Новые проверки при недостающем QA — отдельная условная статья, не синтез готовых актов.
