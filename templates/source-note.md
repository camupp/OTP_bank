# Источник: точное название

Статус: шаблон, не прочитанная публикация.

## Паспорт

- Автор / организация:
- Публикация: дата или «не установлена»; период данных отдельно:
- URL и локальный путь:
- Дата получения:
- Тип: первичные данные / исследование / заявление компании / обзор / методика:
- Глубина чтения: полный текст / выбранные разделы / аннотация / библиография / поисковое описание:

## Что подтверждено

Конкретное утверждение → страница/раздел/таблица. Если приводится цитата, отличать её от пересказа.

## Ограничения

Контекст, выборка, дизайн, определения метрик, коммерческая заинтересованность, переносимость. Чего источник не позволяет утверждать?

## Применение к кейсу

Какой вопрос помогает разобрать; где нужен дополнительный анализ. Проектная идея на основе источника отмечается отдельно от его результата.

## Связь с другими материалами

Версия той же работы, перепечатка, противоречащий результат, используемое утверждение в `research/claims.csv`. Не создавать новый «независимый источник» для другой версии одной статьи.
