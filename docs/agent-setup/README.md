# Агентная система решения кейса

Настроены шесть custom profiles, восемь skills, повторяющийся workflow и хранилище проверяемых снимков. Координатор — основной агент чата. Установка **не запускала** роли, итерации, анализ источников или наполнение wiki.

## Основные документы

- [Workflow](workflow.md) — процесс от общей основы до результата.
- [Система знаний](knowledge-system.md) — отдельный процесс raw → wiki, пока отложенный.
- [Снимки и продолжение](../../analysis/iterations/README.md).
- [Официальные основания Codex](official-sources.md).

## Конфигурация

- [.codex/agents/](../../.codex/agents/README.md): планировщик, аналитик, разработчик концепций, финансист, reviewer и исследователь.
- [.agents/skills/](../../.agents/skills/README.md): knowledge-curation, case-iteration, case-diagnosis, concept-design, case-finance, evidence-check, concept-review, case-storyline.
- [.codex/config.toml](../../.codex/config.toml): максимум два дочерних агента. Модели, provider, reasoning, MCP и разрешения наследуются.

Корневой AGENTS.md и локальные правила определяют обращение с данными и результатами. Конкретные задания задают owned_paths и входы, а не разрешают произвольную запись всем исполнителям.

## Будущий запуск

Прямое поручение `$case-iteration` разрешает координатору делегировать роли, проверить результаты, сохранить снимки и повторять цикл в пределах лимитов без нового подтверждения каждого шага. `$knowledge-curation` остаётся отдельным явным поручением.

Сейчас ни один реальный запуск не создан. Пример будущей команды: «Используй $case-iteration на подготовленной базе, до трёх циклов с двумя ветками». При отсутствии входов skill возвращает needs_inputs, а не начинает скрытое наполнение wiki.

Загрузка профилей зависит от клиента, доверия к папке и текущей сессии. Форматы проверены; реальное обнаружение и вызов моделей пока не проверялись. Если инструмент создания исполнителя не принимает custom profile, протокол предусматривает передачу тех же инструкций и skill в его задание, без выдуманных параметров API.

Старые [пример skill](templates/SKILL.template.md) и [пример TOML](templates/agent.toml.example) остаются учебными. Источник истины системы — установленные profiles/skills и их актуальные контракты.
