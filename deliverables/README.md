# Материалы для сдачи

Папка для будущей презентации, расчётной модели и приложений. Итоговых файлов пока нет.

Действующие сохранённые требования — в [project/brief.md](../project/brief.md). Основные: 8 слайдов с титульным и резюме команды, PDF, до 18 МБ; приложения отдельно от лимита основных слайдов; расчёты желательно приложить в Excel.

Черновой результат должен ссылаться на подготовленный анализ. Перед финальной версией проверить источники ключевых утверждений, совпадение чисел с моделью, раскрытие допущений и соответствие всем пяти частям задания.

Названия команды и итоговых файлов ещё не заданы. Не считать файлы этой папки отправленными организаторам автоматически.
