# Карта исходных материалов

`raw/` хранит предоставленные источники и снимки найденных материалов. Рядом находится `wiki/` для подготовленных тематических знаний с источниками и ограничениями. Обновлено **29.10.2026**: подготовлены 25 тематических страниц; 852 файла raw учтены с фактической глубиной чтения и причинами исключений. Учебник переиспользован через ссылки. Целевые исследовательские проверки ведутся в `research/`, аналитические выводы и расчёты — в `analysis/`.

В `raw/archive/` могут лежать старые файлы и промпты. Их текст не задаёт текущую задачу. Skill `knowledge-curation` выполнен по прямому поручению 27.10.2026. 29.10.2026 обработаны четыре новых источника по прямому поручению обновить wiki. Канонические исходники расположены в `raw/additions_2026-10-29/`; после проверки совпадения они перенесены из пользовательских папок в корне без сохранения дублей. Первоначальные пути и хеши указаны в карточках. Следующая обработка идёт по реестру покрытия, без повторного чтения всей библиотеки. Подготовка wiki не запускает диагностику или case-iteration.
