# Общие синтетические примеры третьего раунда

Все записи вымышленные, только для воспроизводимого desk-check. Это не новые факты банка/вкусы сотрудников. Пять frozen inputs/M05 не меняются. JSON содержит реальные для примера строки случаев, два класса сложности, эталоны/экспозицию и профили часов. Q нужно вычислить заново, quality проверить по той же родительской норме; значения productivity_multiplier не самостоятельная готовая оценка сотрудника.

Индивидуальная группа40 и8команд5 позволяют сравнить две разные поправки с неизменённым parent. Дополнительно: ничья/малые группы/низкаяэкспозиция/критическаяошибка/HRполучатель. Расчёт и короткая карточка сотрудника — проверка формулы/ясности на столе, не эмпирическое понимание.

Труд сравнивается на одной частоте/готовности источника parent, не снижатьQA800ч и не предполагать новыйAPI. Датированное обеспечение/15месяцев/год2/хвосты из002 сохраняются; при неизменной политике денежный core не расширяется.

Профили — независимые сценарии на одном шаблоне. При разворачивании группы каждому участнику/команде присваиваются собственные case-ID и benefit-ID с префиксом его ID; шаблон не означает повторную оплату одной и той же фактической работы. Команда делит один benefit, а не копирует его всем.
