# Проверка доказательств


1. Получи конкретные утверждения или пробел и область результата. Сначала используй уже собранные материалы; делай внешний поиск, когда он действительно нужен назначенной проверке.
2. Для каждого значимого тезиса установи оригинал, locator, дату/период, дизайн, выборку и фактическую глубину чтения. Отдели вывод авторов от переноса на ОТП.
3. Зафиксируй поддержано / противоречит / не проверено, зависимость публикаций, маркетинговый контекст и различия определений. Повторение обзора не добавляет независимых доказательств.
4. Верни evidence.json по контракту `.agents/skills/case-iteration/references/contracts.md`, либо исследовательскую записку для отдельной задачи. Прямые ссылки и локальные места должны быть восстановимы.
5. Новые данные, которые меняют общую основу сравнения, передай координатору до следующей заморозки входов. Не подменяй ими входы только одной ветки и не наполняй wiki автоматически.

Недоступный полный текст честно оставляй пробелом. Если критическое утверждение не подтверждено, оно не становится фактом из-за убедительной формулировки концепции.
