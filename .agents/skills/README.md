# Проектные skills

| Skill | Процедура | Вызов |
|---|---|---|
| [knowledge-curation](knowledge-curation/SKILL.md) | Структурировать назначенные raw в wiki с источниками и покрытием | Только явный; наполнение пока отложено |
| [case-iteration](case-iteration/SKILL.md) | Координация ограниченного итерационного запуска, две ветки, проверки, отбор и снимки | Только явный; запуск пока не поручен |
| [case-diagnosis](case-diagnosis/SKILL.md) | Проверить данные и подготовить общую диагностику | По соответствующему аналитическому заданию |
| [concept-design](concept-design/SKILL.md) | Разработать концепцию по заданию ветки | Используют экземпляры concept-developer |
| [case-finance](case-finance/SKILL.md) | Проверить сопоставимую экономику и балансы | Финансовая проверка |
| [evidence-check](evidence-check/SKILL.md) | Проверить тезис или закрыть точечный пробел | Исследователь / основной агент |
| [concept-review](concept-review/SKILL.md) | Независимо проверить варианты, контроль и прежнего победителя | Reviewer |
| [case-storyline](case-storyline/SKILL.md) | Собрать аргументацию и назначенные материалы для сдачи | Основной агент при порученной финализации |

Навык задаёт способ работы; профиль агента — исполнителя. Наличие файлов не запускает задачи. Редактирование конфигурации не является поручением анализировать raw или генерировать концепции.
