# Техническая проверка системы

Проверка завершена: 27.10.2026. Проверки выполнялись без запуска агентов и без обработки реальных материалов кейса.

## Форматы

- Все восемь установленных skills проходят штатный `quick_validate.py`; содержимое существующего knowledge-curation сохранено без изменений.
- UI YAML содержит корректные имена и подсказки; case-iteration и knowledge-curation настроены на явный вызов.
- Шесть профилей разобраны как TOML: name, description, developer_instructions; модели и разрешения не переопределены.
- config.toml задаёт только предел двух дочерних агентов; глобальные настройки не изменяются.
- Проверены 46 Markdown-документов настройки и 124 локальные ссылки: отсутствующих целей нет. Устаревшие утверждения о невыбранных ролях и пустом config.toml обновлены.

## Helper снапшотов

Во временной папке на искусственных входах проверены:

- Прохождение допустимых раундов, сохранение прежнего победителя и идемпотентное завершение снимка.
- Отклонение противоречия между финансовой проверкой и review.
- Обнаружение изменения замороженных входов и закрытого снимка.
- Отказ при потере прежнего победителя из сравнения.
- Проверка флага изменения основы сравнения.
- Предел итераций, отказ перезаписывать существующий запуск, обнаружение тихой смены лимитов.
- Допустимость отказа всем кандидатам, остановка/продолжение без сброса лимитов.

Это проверки структуры и состояния, не оценка качества будущих идей. Смысловые свойства — независимость подходов, точность анализа, честность расчётов и слепота review — требуют проверки на будущем явно порученном запуске.

## Ограничения

Модели и custom agents не запускались, поведенческая приёмка на кейсе отложена. Наличие файлов и успешный TOML-парсинг не доказывают их обнаружение в уже открытой сессии клиента. Пакет reviewer ограничивается инструкциями и назначенными входами, а не отдельной песочницей.

Raw и содержательная wiki не меняются. Реальные run-папки не создаются; технические сценарии остаются только во временной папке.

Повторная проверка wiki подтверждает: 0 зарегистрированных источников, 0 единиц обработки, 0 тематических страниц. Контрольные суммы существующих файлов knowledge-curation и каркаса wiki совпадают с состоянием до установки системы агентов.
