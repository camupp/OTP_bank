# Одинаковые профили личного пути

Проектные примеры, не распределение сотрудников ОТП. T0 — начало наблюдения после анонса; даты подтверждения/quality-close и когорты брать из концепции, показывая дополнительно задержку к длительности окна. Старый личный баланс во всех профилях0. Не включать добровольные переводы коллег или неназначенные курсы.

Общий скромный **пример реально случившихся событий**, отдельно от сценария без них: один назначенный курс в первый день m1=150C; один опрос m2=50C; день рождения m6=50C; одна ежегодная стажевая дата m12=1000C. Итого1250C/год. Это не гарантированный набор каждого сотрудника, не средняя эмиссия M05; стажевые юбилейные выплаты не складываются. Для длинного ожидания можно повторять только эти явно обозначенные ежегодные события. Для новичка вместо стажевой даты в первый год: первый вход100C m1, eNPS100C m1 и100C m3, успешное испытание500C m3; плюс курс150C m1, опрос50C m2, день рождения50C m6 =1050C. Заполнение профиля1000/1500C показать лишь отдельной добровольной возможностью после реального выполнения, не автоматически каждому новичку.

| Профиль | Общие условия и исход | Что нельзя предположить |
|---|---|---|
| Обычный хороший сотрудник | Сопоставимая группа40, Q1,00, QA98/прочие quality пройдены, обычная экспозиция; ни разу не top. Если новый вид достижения требует дополнительной пользы — отдельно показать исход без неё и с её реальным выполнением | Нельзя автоматически назначить особый вклад ради красивого пути |
| Сильный специалист | Та же группа40, текущий Q1,20, качество пройдено, первое место каждый допустимый цикл в основном примере; отдельно перестал выигрывать/ничья | Первое место не гарантировано сильному; число позиций не число уникальных людей |
| Новичок | Пришёл вT0; после минимальных наблюдений Q1,00/QA98, без top. Показывать время до полного окна и будущую возможность Q1,20 отдельно | Рост от нуля не равен top, прошлой базы нет |
| Участник команды | Группа40, восемь команд по5 с равнымиFTE. Командный Q1,20, первое командное место в примере; отдельно обычная команда Q1,00 без top | Одна командная награда не пять полных личных; личные доли считать |
| Неполная занятость | FTE0,5, группа40 с сопоставимым нормированием, личный Q1,00/QA98; минимум наблюдений достигнут, без top | Не уменьшать гарантию незаметно; при недостигнутом минимуме отдельная задержка |
| Регион с ограниченным выбором | Как обычный Q1,00/no-top, мерч локально отсутствует; проверить выбранные электронные награды по покрытию/магазину/онлайн и минимальному номиналу | Интернет/магазин/пригодность сертификата не равны всеобщей доступности |

Три временных показателя не смешивать: заработанное право; проведённая валюта; первая фактически доступная полезная награда. Если SKU не обеспечен, «после начисления мгновенно» не доказано. Для каждого указывать0R при невыполнении/отсутствии конкурсного места, годовой максимум/пример, отдельныеC иR и роль независимого подтверждения.
