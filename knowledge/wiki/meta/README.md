# Источники, покрытие и состояние

Реестры обновлены **29.10.2026** после первоначального наполнения 27.10. Учтены 852 физических файла raw: 848 прежних и 4 новых исходника, перенесённых из пользовательских папок после проверки совпадения с ранее созданными копиями. Оригинал, извлечение и метаданные одной публикации объединены в семейство. Число файлов не равно числу независимых доказательств.

- [sources.csv](sources.csv) — паспорт, происхождение, глубина чтения и SHA-256 каждого локального файла.
- [processing.csv](processing.csv) — конкретный охват, статус, выходы, причина и продолжение.
- [issues.csv](issues.csv) — противоречия, недоступность, ошибки исходников и ограничения.
- [web-publications.md](web-publications.md) и [CSV каталога](web-publications.csv) — соответствие 58 записей прежней веб-подборки реальным файлам и текущему чтению.
- [Карточки четырёх новых источников](source-notes/SRC-0849.md) — происхождение, первоначальный и канонический пути, версия, реальные границы чтения; рядом SRC-0850–0852.
- [Разборы старых работ](../methods/past-cases-and-transfer.md) и `extracts/` — содержательные выводы и производные тексты для поиска; извлечения не считаются независимыми источниками.
- [progress.md](progress.md) — границы поручения, фактические итоги, проверки и следующий шаг.

`processed` относится к указанному scope; `partial` сохраняет незакрытый объём; `reused` не означает повторного полного чтения; `excluded` сопровождается причиной. Недоступная публикация может существовать только как строка библиографического каталога: отсутствующий локальный файл не выдумывается.
