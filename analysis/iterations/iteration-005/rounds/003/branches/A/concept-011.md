## 2. Механика признания, валют, фондов и администрирования

**Допуск и сопоставимость.** Все7200 сценарно потенциальных участников, включая HR, начальников, новичков и неполное время, получают путь по назначенной работе. 7200 — M05-допущение, не установленный штат. Отдельной заявки на ordinary нет. До усилия человеку назначают одну сопоставимую группу/календарь, размер1–100; крупные группы делят объективно по сервису/каналу/смене, до исходов. Несопоставимые профессии не ранжируют вместе. FTE меняет часы/командные доли, ставка lower одинаковая. Перевод/отпуск не создают пятую награду и не отнимают подтверждённое; независимый владелец определяет один завершаемый сопоставимый путь.

`Q = Σ w_s × [(принятые стандартные единицы_s / доступные производственные часы_s) / эталон_s]`.

Веса экспозиции `w_s`, сложность, смены и инженерный эталон роли фиксирует независимый процессный владелец до периода на год. Реальной исторической медианой ОТП эталон не называется. В синтетике `accepted_units` уже стандартные единицы: повторное умножение на сложность запрещено. Возврат/переоткрытие не создаёт новую единицу. Простои/помощь коллегам исключаются из часов только по независимому журналу. Изменение потока пересчитывает весь затронутый стратум по объявленному правилу, изменение стандарта относится к будущим окнам. Личная прошлая база/рост не используются.

**QA:** `score=max(0,100−2×minor−10×major)` по кейсу, шкала0–100. Дефект учитывается один раз по высшей тяжести; taxonomy и чеклист утверждает safety-владелец до усилия. Для support/backoffice минимум20 разных случаев и выборка20; IT минимум8, выборка`min(20,n)`. При n≤20 проверяются все; при n>20 —20 минимальных SHA256 от `windowID,benefitID,caseID,seed` (UTF8, поля через запятую). Независимый владелец публикует seed после фиксации полного реестра, замена выборки запрещена. Среднее без округления сравнивают с97/98. Критический факт во всём реестре/14-дневном окне отменяет квалификацию независимо от выборки/среднего. Один командный QA-акт используется один раз, без повторного чтения для каждого участника. Проектная шкала не заменяет банковский комплаенс.

**Lower:** каждому одновременно при Q≥1,00 без округления и всех барьерах —500R/цикл, максимум4/год. Квоты успешных нет. **Top:** среди прошедших lower и Q≥1,10 ранжирование по `floor(100Q+0,5)/100`, по убыванию. До усилия пул группы `P=250R×n всех уникальных eligible`; первый слот0,8P, второй0,2P. Команда — одна единица ранжирования, получает одну сумму, делит её по заранее зафиксированным FTE-долям. Не прошедшая личную экспозицию доля остаётся невыданной; не раздаётся другим. Headcount-cap команды отсутствует. Межотделовая команда имеет один benefitID и один источник пула, люди входят в n один раз и в другом ordinary-зачёте этого цикла не участвуют.

Одна зарегистрированная единица до исходов означает top0; команду нельзя искусственно дробить ради соперника. При≥2 зарегистрированных единицах два слота действуют даже при одном квалифицировавшемся: оплачивается80%, остальные20% невыданы. При ничьей k единиц на местах r…r+k−1 сумма предусмотренных денежных слотов этих мест делится между всеми k, включая за границей второго места. Затем FTE; только конечный личный результат округляется вниз до целогоR. Остаток F свободен, истекает квартально только если не обременён правом. Никакого ручного выбора при ничьей.

**Special:** короткое сообщение своё/коллеги: факт, benefitID, доказательство, получатель пользы. Автор сумму не выбирает. Другой владелец подтверждает применение/качество. Готовые записи внутри уровня занимают места по времени независимого подтверждения; точная временная ничья делит занятые слоты уровня. Cap проверяется до назначения, следующая запись может занять свободный слот. Фонд конечный, номинация не гарантирует деньги каждому. После исчерпания — мотивированный ответ и конкретное признание по согласию, без фиктивного обещания следующего фонда. Назначенное — сохранённое право. Ответ/подтверждение≤5рабочих дней, апелляция другому уполномоченному ещё≤5 — проверяемые SLA.
